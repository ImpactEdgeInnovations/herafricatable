# Community Public Profiles

Community public profiles are optional, shareable explanations of an approved
Community. They are not public versions of the Community room.

## Privacy boundary

The public profile can show only:

- Community name, tagline, owner-written overview and intended audience;
- three to six owner-written member benefits;
- owner-approved public host name and introduction;
- an optional aggregate member count;
- published access price and billing interval;
- the next linked, published event without private joining instructions; and
- short-lived signed logo and cover-image URLs.

It never returns posts, replies, member identities, contact details, applications,
payment records, event joining instructions, Host analytics or media storage paths.

## Opening requirements

Public visibility defaults to off. It can turn on only when:

1. the global Communities feature is enabled;
2. the Community is published;
3. all eight Community release checks have passed;
4. an active owner and moderator are present;
5. the Community has a tagline;
6. the overview, audience, host name and host introduction are complete; and
7. at least three clear member benefits have been recorded.

Returning a Community to Draft automatically hides its public profile. This does
not remove the saved draft copy. The owner can also hide the page immediately
without affecting existing members or Community content.

## Host workflow

1. Open **Community → Manage → Look & feel** and save the tagline and optional
   branding.
2. Open **Public page** in the same Host workspace.
3. Save the overview, audience, benefits and owner-approved host introduction.
4. Keep the page as a private draft while reviewing the copy.
5. Complete the private Community release checklist with a Super Admin.
6. Turn on **Make this page shareable** and confirm the action.
7. Open the public page in a separate signed-out browser and verify every field.

## Production acceptance

- A signed-out visitor receives no row while public visibility is off.
- A moderator cannot read or update the owner-only editor record.
- An owner cannot enable a page for a Draft or acceptance-incomplete Community.
- Returning a published Community to Draft hides the page in the same transaction.
- Public responses contain no Community post, member, contact or storage-path data.
- Optional branding URLs expire and cannot be used to enumerate other media.
- Free official, private-review, paid, closed-payment, pending and active-member
  joining states show the correct next action.
- Email-code and temporary-password sign-in return the visitor to the Community
  page using a validated same-site path.
- Every save records only state flags and counts in audit metadata, not public-page
  copy.
